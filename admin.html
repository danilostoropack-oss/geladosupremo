Primeiro acesso: falta conectar o painel ao GitHub. Isso é feito uma única vez; depois basta usuário e senha, em qualquer aparelho.

Como criar a chave
  1. No GitHub, abra Settings › Developer settings › Fine-grained tokens › Generate new token.
  2. Dê um nome (ex.: “Painel Gelado Supremo”) e uma validade.
  3. Em Repository access, escolha Only select repositories e marque geladosupremo.
  4. Em Permissions › Repository permissions, coloque Contents em Read and write.
  5. Gere a chave, copie e cole aqui.
